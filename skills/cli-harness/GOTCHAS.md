# GOTCHAS (macOS)

- **stdin hangs.** `sqlite3` with no SQL argument waits on stdin forever. Always run the backend with `stdin=subprocess.DEVNULL` (the wrapper does this whenever no input is given) and a timeout.
- **Help flags differ.** `--help`, `-help` and `-h` are not interchangeable. sqlite3 accepts both `--help` and `-help`; ffmpeg answers to `-help`; many GNU-style tools only `--help`. Same for version: `--version`, `-version`, `-V`. Try each in order and accept the first with output.
- **Anaconda vs Homebrew binaries.** The same name can resolve to different programs and versions depending on PATH order (`/opt/anaconda3/bin` vs `/opt/homebrew/bin` vs `/usr/bin`). Always resolve with `shutil.which`, never hardcode a path. The resolved path is reported by probe.py; it is not recorded in harness.json.
- **ffmpeg writes to stderr.** Banners, version and help go to stderr, not stdout. Capture both and combine them when probing. Pass `-hide_banner` in wrapper commands.
- **Non-zero exit on help.** Some tools exit 1 or 2 on `--help` or `--version` while printing perfectly good text. Accept non-zero when there is output during probing. In the wrapper, do the opposite: a non-zero exit from a real command is a failure.
- **macOS BSD vs GNU flags.** Tools like `sed`, `date` and `stat` differ from their GNU versions. Probe the installed binary, not what you remember.
- **`--json` is a group option.** It belongs to the top-level group, so it goes before the subcommand: `python3 cli.py --json query ...`, not `python3 cli.py query --json ...`.
- **Argument injection.** A "read-only" wrapper is only as safe as the strings it passes through. Found in the sqlite3 dogfood: `sqlite3 db ".shell cmd"` runs a shell command even with `-readonly`, a column definition containing `); CREATE TABLE ...` adds a second statement, a path starting with `-` is parsed as an option, and the sqlite3 shell's built-in SQL functions `writefile()`, `edit()`, `readfile()` and `load_extension()` touch the filesystem or run commands from plain SELECTs. For sqlite3, always pass `-safe` (3.37+), which disables all of these. Allowlist (regex) anything spliced into the backend's own language, quote literals, and refuse leading `-` and `.` where the backend gives them meaning.
