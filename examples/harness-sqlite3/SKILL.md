# sqlite3 harness

Generated by cli-harness gen_skill.py from cli.py. Do not edit by hand.

## Rules for agents
- Invoke as `python3 cli.py --json <command> [ARGS] [OPTIONS]`. The --json flag goes before the command name.
- Parse stdout as JSON.
- Run any mutating command with --dry-run first: create-table, insert.
- Non-zero exit means failure. Never treat exit 0 alone as proof the output is right.

## Commands
| Command | Description | Options | Arguments |
|---|---|---|---|
| version | Show the backend binary version. | - | - |
| create-table | Create a table (and the database file if it does not exist). | --column, --dry-run | db, table |
| insert | Insert one row into an existing table. | --set, --dry-run | db, table |
| query | Run a read-only SQL query and return the rows. | - | db, sql |
| tables | List user tables in the database. | - | db |
| schema | Show CREATE statements, for one table or for all. | - | db, table |
